# ADR-006: Astro Starlight for documentation

**Date**: 2026-06-08
**Status**: Accepted

**Context**: Documentation is a first-class concern. We need a modern, beginner-friendly docs site.

**Decision**: Use Astro Starlight.

**Rationale**:

- Modern, fast, beautiful out of the box
- Great search, navigation, dark mode
- MDX support for interactive examples
- Easy to maintain alongside the code
- Used by many popular open source projects
